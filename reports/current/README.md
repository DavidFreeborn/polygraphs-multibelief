# Current multibelief study

[Results](results.html) · [Experiment setup](experiment-settings.html) · [Measures](measures.html)

Download [report-and-settings.zip](report-and-settings.zip), extract it and open
`results.html`. All three sheets are self-contained and work offline.

The report shows 45 settings with 100 repetitions each: Baseline, Converging,
Polarizing, Factionalizing and Trust-in-Neighbors across cycle, connected ER .1
and connected ER .2 graphs, in pristine, misinformation and disinformation
environments. Each run has 60 agents and 500 rounds.

G denotes that B is strictly better than A. Initial G probabilities are random
and matched agent by agent across the four belief models. The exact matched
joint-prior construction and likelihood tables are specified in the settings.

## Reproduction

With a C++17 compiler, zlib and Python 3:

```sh
cd reports/current
clang++ -O3 -std=c++17 worker.cpp -lz -o worker
./worker data 500 100 all 1729
python3 validate.py
python3 make_report.py
```

The original worker also generates nine .50-prior trust settings omitted from
the report, giving 5,400 generated and validated runs in total. The retained
report contains 4,500 runs. `study-design.json` defines the seed range and raw
series fields; `summary.json` contains the plotted means and quartiles.
Per-run private/public evidence and posterior records are regenerated by the
worker rather than stored in Git. To regenerate only the HTML from the saved
aggregates, run `python3 make_report.py`.

## Validation

`validation.json` records independent posterior replay, matched G trajectories,
analytical Bala–Goyal checks, source-factor checks and sampled action/metric
checks. These simulations use the exact standalone C++ runner. Native
PolyGraphs/DGL and R execution was not performed for this study.

With the fork’s Python/DGL dependencies installed, `replay_polygraphs.py` can
replay saved evidence through native operations; use `--all` for every run.

[Trust diagnostics](diagnostics/trust/diagnostic-notes.md) record the separate
fixed-evidence and forced-experimentation checks. They do not alter the main study.
