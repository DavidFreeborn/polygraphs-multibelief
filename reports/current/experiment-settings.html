Protocol

SettingSpecification
DesignThe report shows 45 settings × 100 repetitions = 4,500 runs: four belief models and one Trust-in-Neighbors variant, across three topologies and three informational environments. The .50-prior trust runs remain in the original data but are omitted from this report.
Agents and experiments60 agents; 500 rounds; one Bernoulli trial per active agent per round. Known action A has success probability .50; genuine B has .55. Alternatives represented by G=0 have .45.
TopologiesUndirected cycle; connected G(60,.1); connected G(60,.2). ER graphs are rejection-sampled until connected. Each topology’s graph at a seed is reused across all model/environment settings.
Informational environmentsPristine; six misinformants; six disinformants. Unreliable identities are sampled without replacement, fixed during a run, and shared across models/topologies at a seed.
Private data and reportsAll private B trials have success probability .55. Reliable reports equal the source’s private outcome. Misinformants send independent .50 reports; disinformants send independent .45 reports. Their private data remain genuine. One report is shared identically with all recipients. Use own data once and each neighbour report once; there is no forwarding.
DecisionsSynchronous posterior expected-payoff maximisation. Choose B when expected success exceeds .50 with numerical tolerance 10⁻¹⁴; otherwise A. A produces no B data. Every run continues through round 500.
VariablesH is the focal explanatory hypothesis. X,Y are the Factionalizing background nodes. Dᵢ=1 means a successful B trial; reported Dⱼ,ᵢ values are source reports. G=1 means B is strictly better than A. G is deterministic: H=1 for Baseline/trust, H=S=1 for Converging, H=S for Polarizing/Factionalizing.
Base priors QFor each agent and seed, independently draw root-probability parameters u,v,w from Uniform(0,1). The displayed diagrams and S table specify the base model Q before prior matching. Roots H,S have probabilities u,v in the two-node models; H,X,Y have probabilities u,v,w in Factionalizing. In Factionalizing, Q(S=1|X=Y)=.9 and otherwise .1.
Matched initial priors PSet q=u for the corresponding agent across all four belief models. For latent assignment z, P(z)=q Q(z|G=1) if G(z)=1, and P(z)=(1-q) Q(z|G=0) otherwise. Thus every agent has exactly the same randomly drawn P(G=1)=q across models. Q(z|G) is preserved within both strata. Matching G does not also match H or other marginal priors. Matching generally introduces dependencies, replacing independent Uniform root priors in the initial joint distribution.
Calibration node CC=1 is a mathematical representation of the initial prior calibration, not an experimental observation. C and the derived G indicator are suppressed in the diagrams. Let r=Q(G=1), a₁=q/r, a₀=(1-q)/(1-r), and k=1/max(a₀,a₁). Set P(C=1|G=g)=k a_g. Then Q(z|C=1) equals the matched initial prior P(z). The displayed base diagrams omit this initial conditioning; the calibrated prior need not factorise according to their root independence. No extra data are counted and C is not included in diagnostics.
Converging changeOnly H=S=1 predicts .55. The other three assignments predict .45. This replaces the preceding experiment’s two .50 alternatives. No observation identifies separate assignments within G=0.
Trust-in-NeighborsOwn observations depend on H. Each neighbour report depends on the same H and a persistent source variable Rⱼ. Exact factorisation P(H)∏ⱼP(Rⱼ|H) is reconstructed from initial priors and cumulative counts. H’s initial prior is q=u, unchanged from the previous study.
Initial source trustThe retained Trust-in-Neighbors model uses P(Rⱼ=1)=.90 with unreliable sources and 1.00 in pristine settings. Reliability variables start independently of each other and H. Prior 1 is dogmatic; a .90 marginal prior does not encode knowledge of an exact count.
Source alternativesFor Rⱼ=0, report probability is .50 in pristine/misinformation settings and reversed (.55 for H=0, .45 for H=1) in disinformation settings. Agents know the alternative family. Actions and silence are conditioned on, not treated as additional observations.
Belief statisticsMean P(H=1) averages agents’ focal-node probabilities. Population SD uses those same probabilities, with denominator N=60. Mean P(G=1) measures belief that B is better and appears only in the cycle learning check and summary tables. All-agent values are plotted; reliable-agent statistics remain in raw records.
Information statisticsJoint KL is the mean over ordered distinct agent pairs. Joint JS uses equal weights over unordered pairs. Marginal-product JS compares products of each agent’s individual-node marginals. Dependence is mean total correlation KL(joint || own marginal product). G is a deterministic query and C is conditioned on; both are excluded. Logs are natural and no probability smoothing is applied.
Trust statisticsThe three divergence statistics compare H alone because recipients have different source-variable sets. Full-model total correlation is ∑ⱼ I(H;Rⱼ), averaged over agents, and may depend on degree. The two trust curves average directed source-recipient edges grouped by actual source type.
AggregationEach statistic is computed within a run before averaging over 100 runs. Bands are linearly interpolated run-to-run 25th–75th percentiles, not confidence intervals. Record every round 0–100, then every fifth round to 500.
Common scalesIdentical y-axis limits for every panel of a statistic: probabilities/trust 0–1; SD 0–.5; KL 0–6 nats; JS 0–ln(2) nats; dependence 0–1 nats. Limits include plotted means and quartile bands.
Random pairingSeeds 1729–1828. std::mt19937_64, high 53 bits mapped to Uniform[0,1). Stream offsets: +10000 topology; +20000 root priors; +30000 unreliable identities; +40000 experimental outcomes. Full private/report uniform arrays are consumed even for inactive agents.
Execution and scopeStandalone exact C++17 runner with zlib; Python standard-library validation and reporting. Native PolyGraphs/DGL and R were not executed. Finite-horizon descriptive results, without significance claims. The calibrated initial joint is specified by the matched-prior formula; the base S table alone does not describe its conditional probabilities after calibration.

./worker data 500 100 all 1729

study-design.json specifies raw fields and initialisation. Per-run JSON and gzip files retain initial/final joint beliefs, graphs, private outcomes, public reports and actions. summary.json contains plotted means and quartiles. The supplied native replay script requires the full PolyGraphs fork and its DGL dependencies; it was not executed here.
